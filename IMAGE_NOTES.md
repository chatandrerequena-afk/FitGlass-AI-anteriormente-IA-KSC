# Recursos visuales

El proyecto incluye SVG propios y no redistribuye capturas o imágenes de terceros.

- `assets/hero-liquid.svg`: fondo abstracto Liquid Glass.
- `assets/fitglass-icon.svg`: icono de la app.
- `assets/profile-placeholder.svg`: avatar.
- `assets/progress-placeholder.svg`: marcador de progreso.

En `config.js` puedes sustituir `APP_IMAGE_URL` / `HERO_IMAGE_URL` por una URL directa de Imgur que tengas permiso para usar.
